Политика конфиденциальности

Частые вопросы

Как работает синхронизация между устройствами?

Оба телефона должны быть в одной локальной сети (Wi-Fi) с включённым Bluetooth — синхронизация идёт напрямую между устройствами, без интернета и серверов. Включается в Профиль → Семья → Семейный доступ.

Не получается найти второе устройство при синхронизации

Проверьте, что на обоих телефонах включён Wi-Fi и разрешён доступ к локальной сети для Unyana (Настройки → Конфиденциальность → Локальная сеть). Также оба устройства должны быть рядом физически — синхронизация не работает через интернет.

Что будет с данными, если удалить приложение?

Все данные хранятся только на устройстве — при удалении приложения они удаляются вместе с ним, без возможности восстановления. Перед удалением рекомендуем сделать резервную копию (Профиль → Экспорт).

Приложение платное?

Нет, все текущие функции бесплатны и останутся такими.

Privacy Policy

Frequently Asked Questions

How does sync between devices work?

Both phones need to be on the same local Wi-Fi network with Bluetooth enabled — sync happens directly between devices, without the internet or servers. Enable it in Profile → Family → Family Sharing.

Can't find the second device during sync

Check that Wi-Fi is on and local network access is allowed for Unyana on both phones (Settings → Privacy → Local Network). Both devices also need to be physically nearby — sync doesn't work over the internet.

What happens to my data if I delete the app?

All data is stored only on the device — deleting the app deletes the data with it, with no way to recover it. We recommend making a backup before deleting (Profile → Export).

Is the app paid?

No, all current features are free and will stay that way.
